Welcome to Evolution Sandbox!

Hello everyone!

I'm the developer of Evolution Sandbox, an indie creature evolution and ecosystem simulation game.

The idea behind the game is to create a sandbox where players can develop their own species and observe how they interact with their environment.

Development

The game is currently being developed using Base44. I'm working on improving its systems, fixing bugs, and building the features I have planned for the project.

One of my current goals is to prepare a portable version of the game. The portable build already exists, but it still contains bugs and issues that need to be fixed before it can be released.

The project is still in early development, and there's a lot more to come!

Your Feedback Is Welcome!

If you find any bugs, have new ideas, or simply want to share your opinion about the game, feel free to do so!

All feedback, suggestions, and constructive criticism are welcome. I'll be happy to read them!

You can share your thoughts through the GitHub Issues section.

What's Next?

I'll be sharing development updates, new features, ideas, and progress here on GitHub as the project grows.
